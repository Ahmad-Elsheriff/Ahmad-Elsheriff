## 🔥 Featured Projects

### 🛡️ [DeepGuard X: AI Engine & RAG Pipeline](https://github.com/Ahmad-Elsheriff/DeepGuard-X-AI-Engine) *(Graduation Project)*
`Python` `FastAPI` `FAISS` `Ollama` `LLaMA 3` `Tesseract OCR` `Pandas` `Docker`

- Document Q&A system with **semantic chunking, embeddings, FAISS search**, and **page-number citations** back to the source.
- **OCR + table extraction + layout parsing** for scanned pages alongside PDF, DOCX, and TXT.
- **MMR and keyword-boosted retrieval** to improve answer relevance.
- Distributed **Manager–Worker** architecture: up to **2.6x faster** document processing, ~5–8 s end-to-end with local models.
- Manually evaluated on a 10-question multi-document test set: **>85% answer accuracy**.

### 🛒 [Amazon SQL & Business AI Agent](https://github.com/Ahmad-Elsheriff/amazon-sql-ai-agent) *(Official submission, Tips Hindawi Challenge)*
`LangChain` `Ollama (Llama 3)` `FAISS` `HuggingFace` `Streamlit` `SQLite`

- Multi-step agent: **intent routing → text-to-SQL → self-healing correction → RAG business-rule check → response**.
- **Self-healing**: detects SQL execution errors and rewrites the query automatically.
- RAG over business rules and schema guidelines keeps queries and answers within constraints.
- **Arabic RTL Streamlit UI** showing results, generated SQL, and business recommendations.

### 📈 Sales Forecasting & Demand Prediction *(DEPI Graduation Project)*
`Python` `Pandas` `XGBoost` `LightGBM` `LSTM` `Streamlit`

- ML/DL models on **1M+ retail records**, reaching **R² ≈ 0.81**, with an interactive forecasting app.
